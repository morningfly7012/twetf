# 📈 台股 ETF 試算機

一站式台股熱門 ETF 資訊與複利試算工具，純靜態網站，部署於 GitHub Pages。

**線上網址：** https://morningfly7012.github.io/twetf/

## 功能

- **熱門 ETF 總覽**：涵蓋被動市值型（0050、006208、00922）、高股息型（0056、00878、00919、00929、00940）、槓桿／反向型（00631L、00675L、00632R）與主動型（00980A、00981A、00982A），可依類型篩選。
- **ETF 詳細資訊**：發行投信、成立時間、費用、配息頻率、風險等級與商品說明。
- **技術線圖**：內嵌 TradingView 即時線圖，可切換週期與技術指標。
- **前十大成份股**：各 ETF 成份股／持倉示意與權重視覺化。
- **複利計算機**：單筆投入＋每月定期定額試算，含逐年明細、資產成長圖表與通膨調整後實質購買力。
- **投資小教室**：各類型 ETF 特性與風險說明。

## 部署

推送到 `main`（或開發分支）後，GitHub Actions（`.github/workflows/deploy-pages.yml`）會自動將網站部署到 GitHub Pages。

## 免責聲明

本網站僅供參考與教育用途，所有內容均**不構成任何投資建議**。網站中的費用率、報酬率與成份股資料均為整理之示意參考值，實際資訊請以臺灣證券交易所與各發行投信公司公告為準。投資一定有風險，ETF 投資有賺有賠，申購前應詳閱公開說明書。
